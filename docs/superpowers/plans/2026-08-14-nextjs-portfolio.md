# Next.js Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Next.js portfolio foundation with separate pages for home, projects, experience, skills, and contact.

**Architecture:** Use the Next.js App Router with static page components, shared layout components, and a single editable portfolio data module. Pages consume typed data from `src/data/portfolio.ts` and render responsive content with Tailwind CSS.

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, ESLint, npm.

## Global Constraints

- Use separate pages for `/`, `/projects`, `/experience`, `/skills`, and `/contact`.
- Include shared navigation, layout, and footer.
- Store editable portfolio entries in `src/data/portfolio.ts`.
- Do not add a CMS, database, authentication, blog, analytics, or contact form backend.
- Verify with lint, production build, dev server, and route checks when dependencies install successfully.

---

## File Structure

- Create/modify `package.json`, `next.config.ts`, `tsconfig.json`, `eslint.config.mjs`, `postcss.config.mjs`, and framework files through the Next.js scaffolder.
- Modify `src/app/globals.css` for global theme, responsive defaults, and shared utility styling.
- Modify `src/app/layout.tsx` for metadata, shell structure, navigation, and footer.
- Create `src/components/site-header.tsx` for responsive top navigation.
- Create `src/components/site-footer.tsx` for footer links and site close.
- Create `src/data/portfolio.ts` for typed editable placeholder content.
- Modify `src/app/page.tsx` for the home page.
- Create `src/app/projects/page.tsx`, `src/app/experience/page.tsx`, `src/app/skills/page.tsx`, and `src/app/contact/page.tsx`.
